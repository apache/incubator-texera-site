Apache Texera 1.3.0-incubating introduces new storage, AI-integration, workflow, and dataset features, and makes the release artifacts reproducible.

[Source download](https://downloads.apache.org/incubator/texera/1.3.0-incubating/) · [Git tag `v1.3.0-incubating`](https://github.com/apache/texera/releases/tag/v1.3.0-incubating) · [Quick Start](/docs/v1.3.0/getting-started/)

## What's new in 1.3.0-incubating

Major changes include:

### Deployment and storage

- Replaced MinIO with RustFS as the default object store ([#8542](https://github.com/apache/texera/pull/8542)).
- Made Lakekeeper's REST catalog the default Iceberg catalog ([#6049](https://github.com/apache/texera/pull/6049)).
- Allowed Kubernetes deployments to use external S3 storage ([#5932](https://github.com/apache/texera/pull/5932), [#6295](https://github.com/apache/texera/pull/6295)).

### AI integration

- Added a Hugging Face inference operator with text, image and audio tasks ([#5278](https://github.com/apache/texera/pull/5278), [#5320](https://github.com/apache/texera/pull/5320), [#5570](https://github.com/apache/texera/pull/5570), [#5574](https://github.com/apache/texera/pull/5574)).

### Workflow engine and operators

- Added loop operators ([#5700](https://github.com/apache/texera/pull/5700)).
- Added UI parameters for Python UDFs ([#5912](https://github.com/apache/texera/pull/5912)).
- Enabled persistent Python virtual environments for custom packages ([#5577](https://github.com/apache/texera/pull/5577), [#5901](https://github.com/apache/texera/pull/5901)).
- Improved input validation in visualization and ML operators.

### Datasets

- Added dataset contributor metadata, linked to user accounts ([#6952](https://github.com/apache/texera/pull/6952), [#6953](https://github.com/apache/texera/pull/6953), [#7280](https://github.com/apache/texera/pull/7280)).
- Improved resumable dataset uploads and cleanup of stale uploads ([#5929](https://github.com/apache/texera/pull/5929), [#5643](https://github.com/apache/texera/pull/5643)).

### User experience

- Added card views for workflows and datasets ([#4216](https://github.com/apache/texera/pull/4216), [#5947](https://github.com/apache/texera/pull/5947)).
- Added a user feedback dashboard for administrators ([#5893](https://github.com/apache/texera/pull/5893)).
- Added email verification at sign-up ([#7978](https://github.com/apache/texera/pull/7978)).

### Release and quality

- Made the release tarballs and container images reproducible ([#8812](https://github.com/apache/texera/pull/8812)).
- Replaced assets of unknown origin and updated LICENSE and NOTICE.
- Substantially expanded unit test coverage across the codebase.
- Added `bin/local-dev.sh` for running the full stack locally ([#5961](https://github.com/apache/texera/pull/5961)).

For the complete list of changes, see the [full diff](https://github.com/apache/texera/compare/v1.2.0-incubating...v1.3.0-incubating).
