Apache Texera 1.3.0-incubating

Apache Texera 1.3.0-incubating introduces new storage, AI-integration, workflow, and dataset features.

Source download · Git tag v1.3.0-incubating · Quick Start

What’s new in 1.3.0-incubating

Major changes include:

Deployment and storage

  • Replaced MinIO with RustFS as the default object store (#8542).
  • Made Lakekeeper’s REST catalog the default Iceberg catalog (#6049).
  • Added support for external S3 storage in Kubernetes deployments (#5932, #6295).

AI integration

  • Added a Hugging Face inference operator with text, image and audio tasks (#5278, #5320, #5570, #5574).

Workflow engine and operators

  • Added loop operators (#5700).
  • Added UI parameters for Python UDFs (#5912).
  • Enabled persistent Python virtual environments for custom packages (#5577, #5901).
  • Improved input validation in visualization and ML operators.

Datasets

  • Added contributor metadata to datasets, with contributors linked to user accounts (#6952, #6953, #7280).
  • Improved resumable dataset uploads and cleanup of stale uploads (#5929, #5643).

User experience

  • Removed the deprecated Projects feature; upgrading drops the project tables (#7463, #9284).
  • Added card views for workflows and datasets (#4216, #5947).
  • Added a user feedback dashboard for administrators (#5893).
  • Added email verification at sign-up (#7978).

Release and quality

  • Made the release tarballs and container images reproducible (#8812).
  • Replaced bundled icons and images with assets from clearly licensed sources, and updated LICENSE and NOTICE accordingly.
  • Substantially expanded unit test coverage across the codebase.
  • Added bin/local-dev.sh for running the full stack locally (#5961).

For the complete list of changes, see the full diff.

All Apache Texera releases are signed by the project’s release signing keys (KEYS file). Please verify the integrity of any download before use, following the standard ASF procedures: https://www.apache.org/info/verification.html.
